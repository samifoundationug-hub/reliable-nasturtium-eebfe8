# SAMI Foundation Website - Bigger Vision Update

This website package has been updated to strengthen the long-term vision of SAMI Foundation.

Main updates included:

- Updated all main pages to reference the bigger future vision.
- Expanded `future-projects.html` with the five viable future projects.
- Added a new section titled "The Bigger Vision: Building Facilities for Long-Term Impact".
- Explained future facilities needed for larger projects, including:
  - SAMI Family Support and Special Needs Centre
  - Child Development and Inclusive Learning Room
  - Skills Training Workshop
  - Community Training Kitchen and Nutrition Support Area
  - Counselling and Family Guidance Room
  - Emergency Relief and Storage Unit
  - Administration and Reporting Office
  - Mobile Outreach Support
- Explained why future funding may exceed €250,000 as the foundation grows.
- Updated Home, About, Programmes, Governance, Fund, and Contact pages to reflect the bigger picture.
- Kept official documents private and did not add public document downloads.

## Fund page routing

- `fund.html` is the canonical public Special Needs Fund page. Use it for navigation, donor calls to action, and shared links.
- `donate.html` is a compatibility redirect for existing links and bookmarks, with a visible fallback link to `fund.html`. JavaScript preserves query strings and fragments; a meta refresh also works without JavaScript.
- Supporters should continue to request official giving details through `contact.html`.
- Preserve `CNAME` exactly; the custom domain remains `samifoundationug.org`.

Upload the full folder or ZIP package to Netlify for deployment.
